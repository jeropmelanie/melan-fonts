# Melan Font

A custom typeface, made to be sideloaded onto Samsung devices via zFont 3.

## Installation

**Tested on:** Samsung devices, Android 9–13

### Tools you'll need
1. `Melan.ttf` — download from this repo
2. **zFont 3 – Emoji & Font Changer** (Play Store)
3. **zFile** (Play Store) — required for zFont 3 to access your storage

### Steps
1. Download `Melan.ttf` from this repository
2. Install **zFont 3** and **zFile**, both from the Play Store
3. Open zFont 3 — signing in with a **Samsung account** isn't required for this step

   > Real talk: zFont 3 comes packed with hundreds of built-in fonts on its Home tab — go ahead, browse them. But you're here for Melan, so let's set that up first. And keep an eye on this repo, because a cooler upgraded version is coming soon 

4. Go to the **Downloads** tab → tap the **+** icon → tap the folder icon → select `Melan.ttf` (it'll be sitting in your phone storage)
5. Preview it, then tap **Apply** — this installs it as a replacement for the Samsung Sans system font
6. Follow the on-screen steps, starting with installing **Samsung Sans**. Once it finishes downloading, don't tap **Open** — tap **Done**, then press back until you're back in zFont 3
7. Back up your data — but check **Settings only**. Leave Calendar and everything else unchecked
8. At the last step, restore — again, **Settings only**. Once the progress bar hits around 70%, you'll see the magic ✨

> 💡 zFont 3 also shows its own on-screen instructions throughout this process — follow along with those alongside the steps above.

> ⚠️ The restore in step 8 only touches Settings, not your photos or files — but any *settings* you changed after making the backup (dark mode, etc.) may revert too. That's expected, not a bug.

> ⚠️ This has only been tested on Samsung (Android 9–13). zFont 3 does list options for other brands, but these are untested — try at your own risk.

## Known Issues
- Only verified on Samsung, One UI, Android 9–13
- Not tested on other OEMs (Xiaomi, Oppo, Pixel, etc.) — zFont 3 lists options for them, but use at your own risk
- The zFont 3 UI/steps may change slightly with app updates
